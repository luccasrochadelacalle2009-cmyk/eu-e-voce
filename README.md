# US - Our Universe
1. Crie um repositório no GitHub (ex: us)
2. Envie todos estes arquivos para a raiz do repositório
3. Settings > Pages > Source: Deploy from a branch > main / (root)
4. Abra https://SEU-USUARIO.github.io/us/ no celular (online uma vez) e use "Adicionar à tela inicial"
Para atualizar: mude CACHE "us-v1" em sw.js para "us-v2" ao editar o index.html.
