# US - Our Universe (Etapa 2 — interface, temas e interatividade)

## Publicação no GitHub Pages
1. Extraia o ZIP.
2. Envie todos os arquivos deste projeto para a raiz do repositório GitHub (substituindo os arquivos antigos).
3. Em Settings > Pages, mantenha Deploy from a branch e `main` / `(root)`.
4. Aguarde a publicação e abra o endereço do GitHub Pages.

## Atualização do aplicativo instalado
O cache do Service Worker foi atualizado para `us-v4`. Feche e reabra o aplicativo instalado após a publicação. Se a versão antiga continuar aparecendo, feche as abas do site e abra novamente com internet.

## Observação sobre sincronização
Esta versão continua usando `localStorage`: os dados são salvos no navegador/aparelho atual. O backup pode ser exportado e importado manualmente. Para sincronização automática entre dois celulares, será necessário conectar um backend compartilhado com autenticação e regras de acesso.

## Compatibilidade
Aplicação web estática em HTML, CSS e JavaScript, com suporte a PWA.
